Passos dos personagens (FootstepAudio)
=====================================

1) Footsteps - Essentials (já em Assets/Footsteps - Essentials/)
   - Calçada/cidade: Footsteps_Tile (andar + correr)
   - Relva: Footsteps_Grass
   - Também: Gravel, Water, Wood, Mud, etc.

2) Passos conforme o chão (recomendado)
   - Recomeco → Áudio → Configurar passos por superfície (biblioteca + personagens)
   - Detecta automaticamente: Asphalt → ladrilho, Grass → relva, Water → água
   - Terreno NatureTerrain_MatoEstradaLago: usa textura pintada (relva / terra),
     não o «lago» no nome do objeto
   - Biblioteca: Assets/Audio/FootstepSurfaceLibrary.asset
   - Guarda a cena (Ctrl+S) e dá Play

3) Só um som fixo (antigo)
   - Atribuir Footsteps Essentials (calçada) ou (relva)

3) Import settings (se o som falhar ou atrasar)
   - Selecciona uma pasta de .wav no Project
   - Load Type: Decompress On Load
   - Force To Mono: ligado (recomendado)

4) Ajustes no Inspector (componente FootstepAudio)
   - Walk Step Interval / Run Step Interval — ritmo dos passos
   - Volume — volume geral
   - Walk Clips / Run Clips — listas de sons (variação aleatória)

O jogador usa CharacterMover para saber se está a correr (Shift).
NPCs usam a velocidade horizontal do CharacterController.
